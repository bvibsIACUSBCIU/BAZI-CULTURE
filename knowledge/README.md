# Rebuild Knowledge Workspace

Only material admitted through the rebuild source standard belongs here.

```text
knowledge/
  sources/    source provenance and acquisition status
  rules/      schema and reviewed rule cards
  conflicts/  unresolved disagreements between sources or methods
```

Rules:

- A book title in documentation is not an acquired source.
- A candidate URL is not an approved source.
- A source is not production-ready until provenance, rights, transcription, and
  collation checks are complete.
- A rule is not production-ready until its status is `approved`.
- Generated user reports must never retrieve directly from unreviewed raw OCR.
